# 일반 대화 검색 판단 후속 검토

기준 커밋: `afd284d21714a1dced4aa255d70de92b837024fb`. 작업 시작 시 Git 작업 트리는 깨끗했다.

기존 코드에서 `번역 서비스 DeepL이 무엇인지 알려줘`는 `번역` 단어 때문에 외부 조회를 하지 않는 것으로 재현됐다. `아까 말한 제품 지금 가격은?`은 조회가 선택돼도 제품명 대신 대명사를 포함한 원문을 검색했다. 검색 자료가 있으면 `generateGeminiAnswer`의 인용 검증은 생성 결과 전체를 대체할 수 있었다. 앞단의 표현별 자체 답변 판정이 이 검증을 피하는 수단이 되고 있었다.

`publicBotQuestion`, `addressedBot`, `localTask`, `casualTask`, `suppliedTransform`과 한국어 표현별 문장 분할을 제거했다. 명시적 검색 명령·위키 출처 지정 판정, URL의 안전한 본문 조회, 날짜/시각의 결정적 처리, 기존 나이 계산·위키 문서 대상 검증은 유지했다. 기존 단독 검색 도우미의 사실 조회 휴리스틱과 검색어 정제는 유지하지만, 정상 일반 대화의 검색 여부는 그 도우미로 결정하지 않는다.

일반 대화는 기존 답변 모델의 첫 호출에서 시스템 설정, 현재 질문, 대화·영구 기억, 작성자·답장, 첨부 이미지, 제공 URL 본문을 함께 받는다. 기존 `answer`/`emotion` JSON에 `sourcePlan`을 추가한다. 자체 문맥으로 답할 수 있으면 첫 답변을 그대로 사용한다. 외부 근거가 필요하면 자체 답변 부분과 검색어·조회 목적·외부 답변 범위를 함께 반환한다. 앱은 타입, 필수 필드, 길이, 제어문자를 검사하고 최대 한 번의 검색 단계만 실행한다. 모델이 반환한 코드를 실행하거나 임의의 도구를 호출하지 않는다. 검색어 하나에 대한 기존 검색 공급자 재시도/쿼리 변형은 유지한다.

별도의 분류 모델 호출, 새 모델, API tool 선언, 새 response schema는 추가하지 않았다. [Google GenerateContent 문서](https://ai.google.dev/api/generate-content)와 [구조화 출력 문서](https://ai.google.dev/gemini-api/docs/structured-output)를 검토했다. 모델별 native function calling 지원에 의존하지 않고 기존 JSON 요청·파서·키/모델 fallback을 확장하는 방식을 선택했다. 자체 답변은 한 번, 일반 외부 답변은 계획을 포함한 첫 호출과 근거를 받은 후속 호출의 최대 두 번이다. 날짜/시각·체스와 명시적 검색 명령 전용 경로의 기존 처리도 유지한다. 일반 대화의 위키 질문은 계획 후 기존의 결정적 나이·링크 검증을 사용한다.

검색 결과가 비거나 연결이 실패하면 첫 호출의 자체 답변은 유지하고 외부 사실 부분만 유보한다. 외부 답변은 원래 전체 질문·대화·자료와 외부 부분의 요청, 최종 선택된 근거를 받고 생성한다. 인용 검증은 이 별도 외부 생성에만 적용하므로 인용 누락·허위 URL 때문에 자기소개·번역·기억 답변이 사라지지 않는다. 계획이 깨졌거나 구형 JSON만 반환되면 미검증 답변을 노출하지 않고 재질문을 안내한다. 명시적 검색 지시는 유효한 계획이 없어도 원문으로 제한된 조회를 시도한다. 명시적 위키 요청은 공개 웹 근거로 대체하지 않는다.

테스트는 실제 Discord 진입 핸들러와 실제 답변 생성 함수를 격리 실행하고 검색/API 응답만 대체한다. 표현 변형, 혼합 질문, 뉴스 검색 후 요약, 기억으로 제품 식별 후 가격 조회, 제공 글 변환, 인용문 속 검색 문구, 빈 결과·실패·예외, 잘못된 계획, 인용 누락·허위 출처를 확인한다. API payload에 시스템 설정·질문·기억·답장·이미지·제공 본문과 최종 근거가 포함되는지도 검사한다. 실제 외부 모델의 의미 판정 품질을 실계정으로 평가한 결과는 아니다. `sourcePlan`의 의미 판단과 인용된 문서의 주장 뒷받침 여부에는 여전히 모델 판단이 필요하며, URL 검증만으로 사실의 정확성을 보장하지 않는다.

최종 로컬 검증: `npm test` 전체 39개 테스트 파일 통과. `node --check src/index.js`, `git diff --check` 통과. 검색 계획의 자체 답변이 빈 경우 기존 정리/말투 함수가 재질문 문구를 넣지 않도록 처리했으며 실제 말투 함수를 사용하는 회귀 테스트를 추가했다.
